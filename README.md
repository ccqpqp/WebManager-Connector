# WebManager Connector

WebManager의 Windows PC 연결 프로그램 전용 저장소입니다.

- 이 저장소가 연결 프로그램 소스와 업데이트 파일의 유일한 배포 원본입니다.
- `main`에 반영된 코드는 검증 후 GitHub Pages에 ZIP과 버전 정보로 게시됩니다.
- 프로그램의 **업데이트** 버튼과 WebManager의 **PC 프로그램 다시 받기**는 이 저장소의 배포 주소만 사용합니다.
- 로컬 설정, 연결키, 로그 및 Cloudflare/GitHub 자격 증명은 저장소와 ZIP에 포함하지 않습니다.

배포 주소: <https://ccqpqp.github.io/WebManager-Connector/>
